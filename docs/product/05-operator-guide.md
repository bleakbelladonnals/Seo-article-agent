# 操作指南

## 创建内容任务

1. 从工作台进入“内容生产”。
2. 选择状态为“生产就绪”的产品。
3. 选择已批准关键词、目标市场、目标读者与交付物。
4. 点击“创建任务”或“重新运行”。
5. 查看五个 Agent 的进度、证据和结构化契约。
6. 完成后进入审核中心。

## 完成质量审核

1. 在“事实”页签处理基材与交付范围两项关键问题。
2. 根据来源决定盐雾声明的处理方式。
3. 在 SEO、GEO 与品牌页签逐项记录接受或忽略决定。
4. 接受两条 GEO 建议后确认内部准备度为 86。
5. 关键风险归零后点击“审核通过”。

## 管理资产

1. 在内容资产中打开 PHK-01。
2. 查看 V1/V2、知识版本、Prompt、模型策略、人工决定与任务编号。
3. 按需要导出 Markdown、HTML 或 JSON。

## 管理工作区

1. 打开侧栏“工作区设置”。
2. 使用“导出工作区备份”保存 JSON 文件。
3. 使用“恢复工作区备份”选择 v5 或 v4 文件；成功后系统返回工作台。
4. 清除工作区时先点击“清除工作区”，再点击“确认清除”。
