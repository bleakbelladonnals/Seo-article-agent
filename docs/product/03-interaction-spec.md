# 交互规格

## 主流程

1. 在工作台选择“新建内容任务”。
2. 在产品知识中查看 PHK-01 的 BOM、工艺、色板、来源责任人与非电气边界。
3. 在内容生产中选择已批准关键词、市场、受众与交付物，启动五个 Agent。
4. 展开 Agent 契约查看证据输入、输出 Schema、Prompt 和模型策略。
5. 在审核中心处理材质与范围关键问题，接受两条 GEO 建议。
6. 人工批准并创建 V2。
7. 在内容资产中查看 lineage、版本历史并导出三种格式。

## 状态反馈

- **加载**：显示当前 Agent、任务进度和正在使用的证据。
- **错误**：显示失败步骤与重新运行入口。
- **空状态**：没有待审核任务或筛选无结果时给出下一步操作。
- **阻止**：非就绪产品显示具体缺口，创建按钮不可用。
- **警告**：无来源的盐雾声明进入人工判断。
- **成功**：批准后显示 V2、创建人、任务编号、分数和保存时间。
- **恢复**：成功恢复后返回工作台并显示恢复时间；失败不修改当前工作区。

所有按钮具有可访问名称，抽屉支持 Esc 关闭与焦点循环，390px 下主导航、设置、审核卡与编辑区保持可用。
