# 产品定义：LumaFlow AI 内容运营中台

## 产品定位

LumaFlow 面向出口型灯饰五金 OEM 企业的海外营销、SEO 内容与质量团队，统一管理产品知识、内容任务、治理审核和版本资产。

当前业务对象为 `Aurelia PHK-01 仿古黄铜吊灯五金套件`，服务海外灯具品牌、采购经理、产品工程与内容运营人员。

## 业务闭环

```text
已批准产品知识 → 5-Agent 工作流 → 四维审核 → 定点修订 → 人工批准 → 版本资产
```

系统把产品主数据、装配 BOM、色板和内容声明规范转为可复核的任务上下文。每个 Agent 展示任务摘要、输入证据、输出 Schema、Prompt 版本与模型策略，不展示隐藏推理。

## 产品边界

- 浏览器内运行并自动保存，支持 JSON 备份与恢复。
- 保留 `/api/v2` 服务适配契约，但界面不提供运行模式切换。
- GEO Score 是 LumaFlow 内部内容准备度规则，不是行业或搜索平台官方指标。
- 本轮不增加数据库、认证、CMS、WordPress、远程任务队列或模型服务。
- 旧奖牌实现保存在 `legacy/medal-seo-prototype/`，不接入当前应用。
