# 交互规格

## 主路径

1. 重置演示，工作台回到待运行状态。
2. 产品知识查看 PHK-01 的 BOM、工艺、色板、来源与非电气边界。
3. 内容生产以固定 Brief 启动五个模拟 Agent；状态按等待、运行、完成切换。
4. 展开任一 Agent 查看证据输入、输出 Schema、Prompt 和模型路由。
5. 审核中心分别接受材质与范围关键修正；关键计数归零后批准条件才可能满足。
6. 接受两条 GEO 建议；分数分别增加 5，最终为 86。
7. 人工批准创建 V2，并进入内容资产查看 lineage 与导出。

## 关键状态

- **加载**：Agent 有可见进度和当前任务，不使用无反馈等待。
- **错误**：固定失败模式可重试，重试后从失败节点继续。
- **空状态**：浏览型产品明确提示没有演示工作流。
- **警告**：无来源的 500 小时盐雾声明默认需要人工处理。
- **成功**：批准后显示 V2、批准人、分数和保存时间。
- **迁移**：检测到旧案例状态时初始化 PHK-01 并提示案例已升级。

所有按钮提供可访问名称；焦点可见；390px 下主导航、审核卡和编辑区可用。
