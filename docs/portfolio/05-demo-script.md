# 5–7 分钟面试演示脚本

## 0:00–0:40｜先讲问题与边界

“LumaFlow 面向出口型灯饰五金 OEM 的内容团队。我把项目收敛成一条可重复闭环，重点不是生成一篇文章，而是让产品知识、Agent 协作、审核证据和资产版本在同一流程中可追溯。公开版全部是虚构/脱敏数据，Agent 为确定性模拟。”

## 0:40–1:40｜产品知识

进入 **产品知识**，选 `Aurelia PHK-01`：

- 展示 BOM 套件层级和冲压、机加工、AB-07 电镀、机械预装、成套包装流程。
- 指出产品是钢制基材的仿古黄铜效果，不是实心黄铜。
- 展示四个来源版本和不含灯头、电线、驱动、光源、电气认证的边界。

## 1:40–2:40｜五 Agent 生产

进入 **内容生产**，运行固定 Brief。展开一个 Agent：

“界面展示输入证据、输出 Schema、Prompt 版本和模型路由，不展示隐藏推理。150 题评测后没有让一个模型包办：解析和视觉 Brief 路由 Qwen，SEO 与审核路由 DeepSeek，长文路由 GPT-4.1。这里是可预测的 mock，方便面试复现。”

## 2:40–4:25｜治理门禁

进入 **审核中心**：

1. 接受“实心黄铜 → 钢制件 AB-07 仿古黄铜电镀”修正。
2. 尝试说明第二项门禁：非电气套件不能写成可直接安装的完整吊灯；接受定点修正。
3. 指出 500 小时盐雾保证没有来源，不能成为固定承诺。
4. 接受两条 GEO 建议，强调这是内部 rubric，分数从 76 增至 86。

“只有关键事实全部处理，人工批准才开放。建议不是无条件覆盖原文，每次修改都记录来源与决定。”

## 4:25–5:20｜批准与资产

点击批准，进入 **内容资产**：

- PHK-01 从 V1 新增 V2。
- 展开 lineage：知识版本、BOM/色板版本、五个 Prompt、模型路由和批准人完整保存。
- 刷新页面说明浏览器本地持久化。
- 演示 Markdown、HTML、JSON 导出。

## 5:20–6:20｜结果证据

回到 **工作台** 展开“脱敏历史复盘快照”：

“简历数字不是当前站点遥测。每项都展示口径与分母，例如初稿中位数 150→30 分钟、冲突识别 46/50、来源追溯 191/200、UAT 56/60。这个分区把面试中的结果主张变成可检查的产品证据。”

## 收尾

“如果进入生产，下一阶段才会建设服务端鉴权、真实知识检索、评测流水线、队列与审计存储；本轮刻意不把这些伪装成已经上线。”
