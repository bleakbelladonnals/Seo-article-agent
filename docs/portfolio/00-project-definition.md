# 项目定义：LumaFlow AI 内容运营中台

## 重定位

LumaFlow 面向出口型灯饰五金 OEM 企业的海外营销与 SEO 内容团队。项目不再展示成品灯具参数写作，而是展示更接近制造业真实协作的“产品主数据、BOM、表面工艺、交付边界”如何进入受控内容流程。

固定案例为虚构的 `Aurelia PHK-01 仿古黄铜吊灯五金套件`。核心用户是海外内容运营、灯具品牌采购经理和内部审核人。

## 产品命题

将散落的规格表、装配 BOM、色板和内容声明规范，转成一个可追溯的工作闭环：

```text
知识证据 → 5-Agent 确定性模拟 → 四维审核 → 定点修订 → 人工批准 → 版本资产
```

面试版重点证明产品判断和治理设计，而不是展示一个不可验证的聊天窗口。每个 Agent 只展示任务摘要、输入证据、输出 Schema、Prompt 版本和模型路由，不展示隐藏推理。

## 公开边界

- 所有公司、产品、文件、图片、样本和结果均为虚构或脱敏。
- 当前 Demo 数据是确定性模拟；历史指标是脱敏复盘快照，两者在界面中分区展示。
- GEO Score 是 LumaFlow 内部评估规则，不是行业或搜索平台官方指标。
- 无真实 LLM、RAG、数据库、认证、CMS、WordPress 或生产监控。
- 原奖牌内容原型完整保存在 `legacy/medal-seo-prototype/`，不接入本应用。
