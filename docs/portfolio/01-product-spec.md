# 产品规格

## 固定演示对象

- 产品：Aurelia PHK-01 仿古黄铜吊灯五金套件
- 关键词：`antique brass pendant light hardware kit manufacturer`
- 受众：海外灯具品牌与采购经理
- 产品本质：钢制基材 + AB-07 仿古黄铜电镀表面，非实心黄铜
- 包含：吸顶盘、安装支架、链条、牙管、装饰圈、紧固件与成套包装
- 不含：灯头、电线、驱动、光源、电气装配和电气认证

## 五个模块

### 工作台

展示固定任务、两项关键门禁、脱敏历史复盘、150 题模型评测和三轮 UAT。当前 Demo 分数与历史快照必须有明确标签区隔。

### 产品知识

### 内容生产

受控 Brief 驱动五个模拟 Agent：资料解析、SEO 策略、文章生成、视觉创意、质量审核。每步显示 Prompt 版本、模型路由、证据和输出 Schema，并支持一次确定性失败重试。

### 审核中心

四维审核为事实、SEO、GEO、品牌。固定发现包括两项关键问题、一项无来源声明、SEO 标题、两项 GEO 建议和一项品牌建议。两项关键问题未解决时批准按钮必须被门禁阻止。

### 内容资产

批准后新增 PHK-01 V2，保留文章、视觉资产、来源、知识版本、Prompt 版本、模型路由、审核决定和批准人。刷新后仍存在；支持 Markdown、HTML、JSON 导出。
